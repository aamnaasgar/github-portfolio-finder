GitHub Portfolio Finder

A simple web app that lets you search for any GitHub user and instantly view their profile details and repositories.

Live demo: https://aamnaasgar.github.io/github-portfolio-finder/

What it does

Type any GitHub username into the search box and the app shows:

Profile picture, name and bio
Number of public repositories
Number of followers
A link to their GitHub profile
All their repositories as cards, with each repo's description, language, size and star count
Features
Fast search with a single click
Clean dark theme with a glowing neon style
Repository cards with language, size and stars
Works in the browser with no installation and no backend
Uses the public GitHub API
Tech used:
HTML
CSS
JavaScript
GitHub REST API
How to run
Download or clone this repository
Open index.html in any browser
Enter a GitHub username and click Search
